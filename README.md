# zorskill-dev

Maintainer tooling for the [ZorCorp/zorskill](https://github.com/ZorCorp/zorskill) Claude Code plugin marketplace.

Install via the marketplace: `/plugin install zorskill-dev`, then drive with `/zorskill-dev:check`, `/zorskill-dev:release`, `/zorskill-dev:new`.

See `SKILL.md` for the full command reference. Aggregation-side only: it advances submodule pointers and syncs `marketplace.json`; it never pushes to a plugin's own repo.
